# Berkas sumber diagram G1 DayaMuda

Semua diagram G1 tersimpan sebagai berkas `.drawio`. Buka di https://app.diagrams.net
(File > Open from > Device) atau aplikasi draw.io desktop, lalu ubah seperti biasa.
Berkas `.png` dengan nama yang sama adalah gambar yang dipakai di dokumen G1.

| Gambar di G1 | Berkas sumber |
|---|---|
| 4.1 Use case | usecase-dayamuda.drawio |
| 4.2 Flow Map as-is | flowmap-as-is.drawio |
| 4.3 Flow Map to-be | flowmap-to-be.drawio |
| 4.4 DFD konteks | dfd-0-konteks.drawio |
| 4.5a, 4.5b DFD level 1 | dfd-1-level1-a.drawio, dfd-1-level1-b.drawio |
| 4.6 DFD level 2 P-1 | dfd-2-level2-p1.drawio |
| 4.7 DFD level 2 P-3 | dfd-2-level2-p3.drawio |
| 4.8a, 4.8b ERD | erd-1-pendaftaran.drawio, erd-2-pelaksanaan.drawio |
| 5.1 Arsitektur | arsitektur-dayamuda.drawio |
| 5.2 s.d. 5.4 Wireframe | wireframe-1-antrean.drawio, wireframe-2-presensi.drawio, wireframe-3-evaluasi.drawio |

Folder `_generator/` berisi skrip Python yang membuat berkas-berkas di atas (opsional).
Kalau diagram diubah langsung di draw.io, ekspor ulang PNG-nya (File > Export as > PNG)
dan ganti gambar di dokumen.
